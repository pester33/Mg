# MG Menu (Geode mod)

Hack menu for Geometry Dash on PC and Android, with automatic Safe Mode.

## Download
- **GD 2.2091** (Geode 6): https://github.com/pester33/Mg/releases/download/latest-build-2.2091/pester.mg-menu.geode
- **GD 2.2081** (Geode 5.11.2): https://github.com/pester33/Mg/releases/download/latest-build/pester.mg-menu.geode

Put the `.geode` file in `Geometry Dash/geode/mods` and restart GD. The mod updates itself after that.
